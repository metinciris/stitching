# MicroStitch Studio

**Whole-slide-style stitching for smartphone microscope and pathology images.**

MicroStitch Studio is an open-source Python application for combining overlapping microscope photographs into a single high-resolution mosaic while trying to preserve tissue geometry, H&E color balance, and nuclear detail.

It is designed for a problem that ordinary panorama software does not handle well: microscope fields photographed through an eyepiece, often with circular black borders, uneven illumination, repeated texture, small rotations, and sometimes more than one objective magnification.

![MicroStitch Studio interface](screen.PNG)

> **Project status:** active / experimental research software. The repository includes a real sample dataset and generated outputs so changes can be compared against a known case.

## Why MicroStitch Studio?

Generic panorama stitchers are optimized for natural scenes. Histology has different failure modes: a registration error of only a few pixels can duplicate nuclei, blur gland borders, or create false-looking seams. MicroStitch therefore favors constrained transforms, global registration, objective grouping, and narrow seam selection over aggressive perspective warping or broad alpha averaging.

### Current highlights

- SIFT-based feature detection and robust pairwise matching
- RANSAC similarity / partial-affine registration
- Global pose-graph optimization to reduce cumulative drift
- Automatic grouping of images that appear to come from different objective magnifications
- Black eyepiece / invalid-border masking
- Illumination and white-background normalization designed to minimize H&E chroma changes
- Graph-cut, Voronoi, and crisp seam strategies
- Full-resolution rendering with Lanczos resampling
- PNG, JPEG preview, JSON quality report, and pyramidal OME-TIFF export
- PyQt5 desktop interface with drag-and-drop, thumbnails, progress logging, quality presets, and zoomable preview

## Installation

### Requirements

- Python **3.11+** recommended
- Windows 10/11 is the primary tested desktop environment
- macOS/Linux may work if PyQt5 and OpenCV dependencies are available

Clone the repository:

```bash
git clone https://github.com/metinciris/stitching.git
cd stitching
```

Create a virtual environment (recommended):

```bash
python -m venv .venv
```

Windows:

```bat
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

Install dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run

```bash
python MicroStitch_Studio.py
```

On Windows you can also use:

```bat
Run_MicroStitch.bat
```

## Basic workflow

1. Click **Add images** or **Add folder**, or drag image files into the left panel.
2. Choose the output folder.
3. Start with the **Balanced** profile and **graphcut** seam strategy.
4. Keep **hybrid WSI** disabled unless you intentionally want output from different objective groups combined.
5. Click **STITCH WHOLE SLIDE**.
6. Review the **Preview**, **Process log**, and registration summary.
7. Inspect the exported full-resolution image and `stitch_report.json` before relying on the result.

## Processing profiles

| Profile | Typical use | Trade-off |
|---|---|---|
| Fast | quick test / many frames | fewer features and lower matching work resolution |
| Balanced | recommended default | good speed/quality balance |
| Maximum quality | difficult or high-detail sets | slower and more memory intensive |
| Custom | advanced users | manual control of matching and rendering parameters |

## Outputs

Depending on selected settings, each detected objective group can produce:

```text
objective_1.png
objective_1_preview.jpg
objective_1.ome.tif
objective_2.png
objective_2_preview.jpg
objective_2.ome.tif
stitch_report.json
```

The JSON report records settings, detected tiles, pairwise matches, objective grouping, registration information, and output metadata. It is useful for debugging and for comparing algorithm changes.

## How the stitching pipeline works

At a high level:

```text
Images
  ↓
valid-field / eyepiece masking
  ↓
illumination + white-point estimation
  ↓
SIFT features on tissue-relevant regions
  ↓
pairwise matching + Lowe test + RANSAC
  ↓
pose graph
  ↓
global robust optimization
  ↓
objective / scale grouping
  ↓
full-resolution warp
  ↓
tissue-aware seam selection
  ↓
limited blending
  ↓
PNG / OME-TIFF / preview / JSON report
```

The application deliberately avoids treating the growing blended canvas as the next matching target. Pairwise relationships are estimated first and then solved globally, which helps limit accumulated drift.

## Image acquisition recommendations

Software cannot recover detail that was never captured. For best results:

- keep the same objective within one acquisition pass
- lock phone exposure, white balance, focus, and digital zoom if possible
- avoid digital zoom
- keep approximately **30–45% tissue overlap** between neighboring fields
- scan in a predictable row-by-row / serpentine pattern
- avoid motion blur and severe focus changes
- keep the eyepiece and phone position stable
- capture separate passes when changing objective magnification

## Histopathology integrity

MicroStitch Studio is intended to preserve captured image information rather than invent missing detail.

By default, the project should **not** use generative super-resolution, AI hallucination-based detail enhancement, automatic stain replacement, or other operations that may create microscopic structures that were not present in the source image.

Optional appearance enhancement should always remain separate from the geometrically stitched original output.

## Contributing

Contributions are welcome. Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) before submitting significant changes.

Especially useful contributions include:

- registration robustness and loop-closure diagnostics
- objective/magnification clustering
- tissue-aware seam costs
- focus / blur scoring and frame rejection
- memory-efficient tiled rendering
- OpenSlide-compatible pyramidal export
- automated regression tests using the sample dataset
- GUI accessibility and readability improvements

When changing registration or blending behavior, compare the result with the files in `sample/sample_MicroStitch_Output/` and report whether geometry, seams, colors, or registration metrics changed.

## AI-assisted development

AI coding tools should read [`AGENTS.md`](AGENTS.md) before modifying the project. It defines non-negotiable constraints for tissue geometry, H&E color preservation, objective grouping, test strategy, and sample-image handling.
